# Манулы

Мод для Minecraft (Fabric), добавляет манула (*Otocolobus manul*) — приземистую
пушистую кошку каменистых степей и заснеженных холмов. Не перекрашенная
ванильная кошка: своя модель, своя текстура, своё поведение и своя механика
приручения.

* Minecraft 26.2
* Fabric Loader 0.19.3, Fabric API 0.157.0+26.2
* Java 25
* Автор: sht0rmi

Кроме основной версии в репозитории есть порт на Minecraft 1.21.4
(`mc-1.21.4/`) и аддон для Bedrock Edition (`bedrock/`) — см. раздел
[Другие версии игры](#другие-версии-игры).

## Внешность

Модель своя, срисована с фотографий:

* тело 9 × 7 × 13 на коротких лапах — в длину почти вдвое больше, чем в высоту;
* «юбка» 10 × 4 × 14 вокруг низа: длинная шерсть свисает и прячет лапы;
* голова 9 × 6 × 6, шире тела и ниже его — широкий череп, низкий лоб;
* шеи нет, голова приставлена вплотную;
* воротник по бокам головы, за счёт него морда широкая и плоская;
* хвост толстый, из двух звеньев, с чёрным кончиком.

От земли до темени 10,5 пикселя, всё влезает в хитбокс 0,8 × 0,7.

Котёнок — та же сетка, уменьшенная вдвое в рендере, плюс голова покрупнее
относительно тела. Отдельной детской сетки нет: ванильный `BabyModelTransform`
сдвигает уже готовые позы, и поза, задающая высоту части абсолютным числом,
этот сдвиг затирает — котёнок повисает над своими же лапами. Масштаб в рендере
применяется вокруг ступней, так что оторвать от земли не может.

## Окрас

Кроме серебристо-серого бывает рыжий (краснопесчаный) манул:

* при спавне рыжим оказывается один зверь из восьми;
* котёнок берёт окрас случайного родителя, один из шестнадцати мутирует, так
  что рыжих можно вывести и от пары серых;
* окрас пишется в сохранение тегом `Ginger`:
  `/summon manul:manul ~ ~ ~ {Ginger:1b}`.

Текстуру 128 × 64 рисует `tools/gen_textures.py` — считает прямоугольники
граней из тех же размеров кубов, что стоят в модели, и проверяет развёртку на
пересечения. Рыжая получается перекраской готовой развёртки по таблице цветов,
поэтому рисунок у обоих окрасов гарантированно один и тот же.

Флаг `--preview <папка>` кладёт рядом развёртку в увеличенном виде и крупный
план головы — лицо там всего 9 × 6 пикселей, иначе не разглядеть.

## Приручение

Приручить с первой рыбы не получится: у манула есть скрытое доверие 0…100.

| Событие | Доверие |
|---|---|
| Скормить сырого кролика, треску или лосося | +12 |
| Получить удар от игрока | −25 |

Пока доверие ниже 30, манул убегает и шипит. С 70 каждое кормление даёт шанс
1 к 3 на приручение.

Дикий манул убегает только от игрока в полный рост, крадущегося подпускает.
Рабочая тактика: присесть, подойти, покормить, повторить.

## Поведение

* шипит, если не доверяет: замирает, прижимает уши, отдельная поза в модели;
* греется на солнце — днём под открытым небом садится и подолгу сидит,
  приручённый при этом урчит;
* охотится на кроликов;
* приручённый ходит за хозяином, садится по команде, защищает и защищается,
  размножается (котята рождаются приручёнными).

Спавн: заснеженные равнины и склоны, роща, луг, продуваемые холмы, каменистые
пики, саванновое плато. Группами по 1–2, в любое время суток — ограничения по
освещённости мод не ставит.

## Звук

Голос настоящий, из записи `sounds_src/manul_sound_original.ogg`. Исходник был
стерео, 16 секунд и тихий, а игре нужно моно (у стерео не работает затухание по
расстоянию) и коротко. Обработка — `tools/prep_sound.py`: вырезан единственный
крик, сведено в моно, срезан неслышный инфраниз, вычтен фоновый шум, фейды и
нормализация. Результат — `assets/manul/sounds/ambient1.ogg`, моно, 2 секунды.

В `sounds_src/` лежат три варианта обработки, чтобы выбрать на слух; в моде
стоит `cand_a_hpf70.ogg`. Заменить — просто скопировать нужный поверх
`assets/manul/sounds/ambient1.ogg`.

Шипение, урчание, урон и смерть пока ванильные (котёнок и оцелот) — своих
записей под них нет. Когда появятся: положить моно OGG в
`assets/manul/sounds/`, добавить поле в `ManulSounds`, событие в `sounds.json`,
субтитр в локализацию и переключить вызов в `ManulEntity`.

Скрипт умеет и разбирать чужие записи:

```
python tools/prep_sound.py analyze <файл>              обзор и поиск звуков
python tools/prep_sound.py zoom <файл> <от> <до>       огибающая по 20 мс
python tools/prep_sound.py noise <файл> <от> <до>      спектр по полосам
python tools/prep_sound.py cut <файл> <от> <до> <out>  вырезать и обработать
```

Нужны `soundfile` и `numpy`. Параметры OGG без зависимостей читает
`tools/ogg_info.py`.

## Сборка

```
./gradlew build
```

Готовый `.jar` появится в `build/libs/`, для запуска нужны Fabric Loader и
Fabric API.

Своя Java не нужна: мод компилируется под 25, но Gradle сам берёт JDK 25 через
toolchain, а если такого в системе нет — скачивает (~135 МБ один раз в
`~/.gradle/jdks`). Тем же JDK работает и демон Gradle, это задано в
`gradle/gradle-daemon-jvm.properties`. Играть с готовым модом JDK тоже не нужен,
лончер приносит свою Java.

Текстуры в репозитории уже готовые, но если правишь модель — перерисуй их той же
командой:

```
python tools/gen_textures.py                     перерисовать текстуры
python tools/gen_textures.py --preview %TEMP%    ещё и увеличенные копии
```

Зависимостей у генератора нет: полотно — `bytearray`, PNG пишется через `zlib`,
ни numpy, ни Pillow не нужны.

## Другие версии игры

### Minecraft 1.21.4 (Fabric)

Отдельный подпроект `mc-1.21.4/` со своим Gradle: тот же мод под старое API.

```
cd mc-1.21.4
./gradlew build
```

`.jar` появится в `mc-1.21.4/build/libs/`. Нужны Fabric Loader 0.16.10 и Fabric
API 0.119.4+1.21.4.

Отличия от основной версии — только в API, поведение и модель те же. Что
пришлось развести по версиям: Loom взят постарее (1.13.6 под старым id
`fabric-loom`, иначе он требует access widener'ы Fabric API в official-namespace,
а для 1.21.4 они ещё в intermediary), код компилируется JDK 25 с
`options.release = 21`, а сама игра запускается на JDK 21 — путь к нему стоит в
`mc-1.21.4/gradle.properties` (`org.gradle.java.installations.paths`), поправь
под себя, если JDK 21 лежит в другом месте.

Проверено: `./gradlew build` собирает, `./gradlew runServer` поднимает сервер и
пишет в лог строку загрузки мода. `runClient` не запускался — клиент 1.21.4
тянет свои ресурсы, а это несколько сотен мегабайт.

### Bedrock Edition

Аддон из двух паков в `bedrock/`, собирается в один файл:

```
python bedrock/build_mcaddon.py
```

Результат — `bedrock/dist/manul-1.0.0.mcaddon`, открывается двойным щелчком.
Подробности, установка вручную и список расхождений с джавовой версией —
[bedrock/README.md](bedrock/README.md).

Модель, текстуры и развёртка те же: геометрия пересчитана из `ManulModel` по
правилу `y_bedrock = 24 − y_java`, поэтому `manul.png` и `manul_ginger.png`
подходят как есть. Доверие, которого в Bedrock нет как числа, разложено на семь
групп-ступеней. В игре аддон не проверялся: Bedrock здесь не запускается.

## Структура

```
src/main/java/com/sht0rmi/manul/
	ManulMod.java              точка входа
	entity/ManulEntity.java    сущность, доверие, взаимодействие
	entity/goal/               шипение, солнечные ванны
	registry/                  сущности, предметы, звуки
	world/ManulSpawns.java     естественный спавн
src/main/resources/assets/manul/
	sounds.json                описание звуковых событий
	sounds/ambient1.ogg        голос манула
	textures/entity/           manul.png и manul_ginger.png
src/client/java/com/sht0rmi/manul/client/
	ManulModClient.java        регистрация слоёв и рендера
	render/ManulModel.java     геометрия и анимация
	render/ManulRenderer.java  рендер, размер котёнка, выбор текстуры
	render/ManulRenderState.java
sounds_src/                    исходная запись и варианты обработки
tools/gen_textures.py          генератор текстур из развёртки модели
tools/prep_sound.py            разбор и подготовка звука
tools/ogg_info.py              параметры OGG без зависимостей
mc-1.21.4/                     порт на 1.21.4: свой Gradle, те же исходники
bedrock/
	manul_bp/                  пак поведения
	manul_rp/                  пак ресурсов: модель, текстуры, анимации
	build_mcaddon.py           проверка паков и сборка .mcaddon
```
